**Vercel**, **Netlify**, and **Cloudflare Pages** all take a Git repo (or CLI drop) and put an Astro or Next site on a global edge. The fork is how the bill meters: Vercel usage credits and seats, Netlify credit packs, Cloudflare free static plus Workers for Functions.

Prices below come from [vercel.com/pricing](https://vercel.com/pricing), [netlify.com/pricing](https://www.netlify.com/pricing/), [Cloudflare Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/), [Pages Functions pricing](https://developers.cloudflare.com/pages/functions/pricing/), [Pages limits](https://developers.cloudflare.com/pages/platform/limits/), and [cloudflare.com/plans](https://www.cloudflare.com/plans/), checked **16 Sep 2026**. Search ranks and volumes unknown. MorningStacks has not timed a bake-off on identical Astro/Next apps across all three.

## What is each host built for?

**Vercel** is the commercial home of Next.js. Previews, ISR, Fluid compute, and the Pro dashboard are the product. Hobby is for personal, non-commercial use per their FAQ. Commercial work lands on Pro.

**Netlify** is a framework-agnostic Git host with a credit wallet. Free, Personal, and Pro buy monthly credits. Deploys, bandwidth, compute, and web requests spend those credits. Agent runners and a Netlify Database show up on the pricing cards now.

**Cloudflare Pages** sits on the Cloudflare network. Static asset requests are free and unlimited on Free and Paid. **Pages Functions** (anything that is not a static asset) count as Workers. Build concurrency and monthly build caps rise with the Cloudflare zone plan (Free / Pro / Business).

Same category on a comparison page. Different default: Next-shaped platform, credit wallet, or free static + Workers meter.

## How do Astro and Next fit on each platform?

**Next on Vercel** is the path of least surprise: App Router, ISR meters, Image Optimization line items, and Fluid Active CPU (**from $0.128/hr** on Pro after Hobby's included hours) live on the same pricing grid.

**Next on Netlify or Cloudflare** works through adapters and framework docs. You still ship. You own more of the "does SSR count as a Function / credit burn" homework.

**Astro** is often mostly static HTML after build. That favors Cloudflare Pages (static free) and Netlify Free while you stay inside credits. SSR islands or server endpoints start the Function/credit meter on Cloudflare and Netlify, and Vercel Functions on Vercel.

If your marketing site is Astro content collections with almost no server code, Cloudflare Pages Free is hard to beat on pure transfer cost. If your product is a Next SaaS with auth routes and ISR, Vercel Pro is usually the calmer ops choice for a solo founder who already thinks in Next.

## What should you watch on the bill?

**Vercel Pro:** seats + usage. One Developer seat is baked into the **$20** story many teams quote; extra Developers are **$20/mo** each on the pricing table. Fast Data Transfer and edge requests grow with traffic. Set spend management before a launch spike.

**Netlify:** credits. A chatty production deploy loop can burn the Free **300** faster than bandwidth. Personal at **$9** is the quiet upgrade for a solo operator who ships daily.

**Cloudflare Pages:** builds and Functions. Static readers are cheap. A Function on every document request will hit Workers Free's **100k**/day ceiling, then you decide on Workers Paid.

Preview URLs matter for agency and client work. All three do deploy previews. Cloudflare can put Access in front of previews if you already live in that dashboard.

## Which host fits which solo operator?

**Lean Vercel when:**

- Next is the product, not a side static brochure.
- You want one vendor that documents ISR, images, and Fluid compute on the same page.
- **$20/mo** Pro plus usage is fine once Hobby's commercial limit bites.

**Lean Netlify when:**

- You hop frameworks (Astro this quarter, something else later) and want a credit wallet.
- Free or Personal covers early traffic and you like unlimited members on Pro without per-seat drama.
- You already know how to read credit burn in the dashboard.

**Lean Cloudflare Pages when:**

- The site is mostly static and you care about unlimited static bandwidth.
- You already pay Cloudflare for DNS/WAF, or you want Workers, R2, and KV next door.
- You're willing to treat Functions as a Workers bill (**$5** floor when you leave Free).

## How should you decide in one afternoon?

1. Write down static vs SSR. Pure Astro marketing → try **Cloudflare Pages** Free first.
2. Next App Router product with server routes → open **Vercel** Pro pricing and model seats + transfer.
3. Multi-framework shop or credit-shaped mental model → open **Netlify** Free/Personal and estimate credits from deploys + bandwidth.
4. Confirm stickers yourself on [vercel.com/pricing](https://vercel.com/pricing), [netlify.com/pricing](https://www.netlify.com/pricing/), and [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/).
5. Turn on spend alerts the same day you point production DNS.
