Supabase pricing has two layers, and most surprise bills come from the second one. The plan fee is the part everyone quotes: $0, $25, or $599. Compute is billed separately, per project, by the hour.

Once you see how those two layers fit, the bill is easy to predict. We went through the full [Supabase pricing page](https://supabase.com/pricing) and the cost-control docs on **8 October 2026** and worked out what real setups cost each month.

## What are Supabase's plans and prices?

| Monthly active users | 50,000 | 100,000, then $0.00325 each | Same as Pro | Custom |
| Database disk | 500 MB (shared CPU, 500 MB RAM) | 8 GB per project, then $0.125/GB | Same as Pro | Custom |
| Egress | 5 GB | 250 GB, then $0.09/GB | Same as Pro | Custom |

</div>

Source: [Supabase pricing](https://supabase.com/pricing), checked 8 Oct 2026. Team adds SOC 2, ISO 27001, SSO for the dashboard, and an optional HIPAA add-on.

Pro is billed up front each month. Overages land at the end of the billing cycle.

## How does Supabase compute pricing work?

Every project runs on its own compute instance, and each instance has an hourly price. Pro and Team include **$10 a month in compute credit**, which covers exactly one Micro instance.

<div class="table-wrap">

| Compute size | Memory | Monthly price |
| --- | --- | --- |
| Micro | 1 GB | $10 |
| Small | 2 GB | $15 |
| Medium | 4 GB | $60 |
| Large | 8 GB (2 vCPU) | $110 |
| XL | | $210 |
| 2XL | | $410 |
| 4XL | | $960 |
| 8XL | | $1,870 |
| 12XL | | $2,800 |
| 16XL | | $3,730 |

</div>

Source: [Supabase pricing](https://supabase.com/pricing). Disk includes 3,000 IOPS and 125 MB/s of throughput; extra IOPS cost $0.024 each and extra throughput $0.095 per MB/s.

Supabase's own example: a Pro org with 2 Micro projects pays $25 + $10 + $10, minus the $10 credit, which is **$35 a month**. The credit applies once per organization. It doesn't multiply with your projects.

This is why "Supabase is $25" gets people in trouble. A staging project, a side project, and production on one Pro org is $45 before any usage.

## What are the Free plan's real limits?

The Free plan is generous for prototypes and strict about idle projects:

- **Pauses after 1 week of inactivity.** You can restore it, but a paused demo won't load for a visitor.
- **2 active projects** per account.
- **500 MB database** on shared CPU with 500 MB of RAM.
- **500,000 Edge Function invocations**, 200 Realtime peak connections, and 2 million Realtime messages.
- **50 MB max file upload** and 1 day of logs.

If anything public depends on it, move to Pro. The pause rule alone makes Free a bad home for production.

## What do Pro usage overages cost?

Beyond the table above, Pro meters a few more things:

- **Edge Functions:** 2 million invocations included, then $2 per million.
- **Realtime:** 500 peak connections included, then $10 per 1,000. 5 million messages included, then $2.50 per million.
- **Image transformations:** 100 origin images included, then $5 per 1,000.
- **Max upload size:** 500 GB per file.

## How do you keep a Supabase bill predictable?

Start with the **spend cap**, which is on by default for Pro. Per the [cost-control docs](https://supabase.com/docs/guides/platform/cost-control), when it's on and you pass a quota, Supabase blocks further use of that item until the next cycle instead of charging you.

It covers disk size, egress, Edge Function invocations, logs, MAU, Realtime, storage, and image transformations. It doesn't cover compute, branching, read replicas, custom domains, extra IOPS or throughput, IPv4, log drains, phone MFA, or point-in-time recovery.

A few more habits that help:

1. **Count projects.** Each project is its own compute line, even inside one org. Pause or delete the ones you don't use.
2. **Right-size compute.** Moving from Micro to Medium costs $50 more a month. Check your database metrics first.
3. **Cache what you serve.** Cached egress is $0.03/GB against $0.09/GB uncached.
4. **Watch the Upcoming Invoice.** The billing page shows a running estimate for the cycle.

For a typical SaaS MVP, Pro at $25 to $35 is hard to beat for a hosted Postgres database with auth, storage, and Realtime included. Our [Supabase vs Firebase](/developer-tools/supabase-vs-firebase-saas-mvp/) comparison covers when Firebase's pay-as-you-go Blaze plan works out cheaper.
